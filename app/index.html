What is MIL-DTL-38999?

MIL-DTL-38999 ("D38999") is a U.S. military standard for rugged circular connectors used in aerospace, defense, and other harsh-environment electronics. Each part number is a code describing the connector's shell style, finish, size, internal pin layout, contact type, and keying.
